# Локальні навчальні матеріали

Запустіть ` .\tools\demo\start.cmd ` у корені проєкту та дочекайтеся `Demo Firebase is running`.
Залиште термінал відкритим. У debug-застосунку ввімкніть «Локальне тестування».

Демо студент лише один; старі додаткові демо студенти видаляються під час підготовки.

У каталозі два матеріали:
- «Бази даних: таблиці та SQL» — таблиці, ключі, SQL, JOIN, транзакції та вправи.
- «Англійська для ІТ: спілкування в команді» — словник, граматика, діалог та вправи.

Це чотиристорінкові PDF з великими заголовками, таблицями й вправами. Конспект баз даних — українською, англійська — з перекладом та відповідями. Записи зберігаються у Firestore,
а самі файли завантажуються у Firebase Storage локального емулятора.
Їх можна відкрити та завантажити в застосунку. Це локальна база demo-stefanykhub;
основний проєкт Firebase не змінюється. Адреса 10.0.2.2 працює для Android Emulator.
Після зупинки серверів файли недоступні; наступний запуск відтворює навчальні дані.

Інтерфейс бази: http://127.0.0.1:4000.
Повторне завантаження даних при запущених серверах: `node tools/demo/seed.mjs`.
Перевірка входу, прав і обох PDF: `node tools/demo/verify.mjs`.

Для справжнього акаунта вимкніть «Локальне тестування».
Основний режим тепер також потребує HTTPS API безпеки, заданого через SECURITY_API_URL.
Реєстрація, CAPTCHA, листи активації, TOTP 2FA, журнал і блокування описані в ACCOUNT_SECURITY.md.
У локальному режимі API стартує разом з емуляторами; листи для перевірки записуються в tools/demo/.security-local/.
