# Оперативні оголошення

1. Викладач відкриває профіль → «📢 Оголошення» → «Створити оголошення».
2. Обирає дисципліну зі своїх опублікованих матеріалів, область «Дисципліна» або «Матеріал», вводить до 500 символів та публікує. Для області «Матеріал» додатково обирає власний матеріал цієї дисципліни.
3. Для області «Дисципліна» студент обирає цю дисципліну у фільтрі каталогу: над статистикою закріплюється банер. Для області «Матеріал» банер відображається в картці матеріалу, його описі й ридері. Натискання відкриває всі оголошення відповідної області.
4. Автор може видалити своє оголошення з підтвердженням. Адміністратор бачить усі оголошення і може їх видаляти, а також публікувати для дисциплін каталогу.

Вибір дисципліни — поточний фільтр каталогу, без окремої системи підписок. Без обраної дисципліни банер не показується. Це канал усередині додатка, без фонових push-сповіщень. Оголошення залишаються закріпленими до видалення; старі не зникають автоматично.

Дані: `announcements/{autoId}` із authorId, authorName, materialId, materialTitle, subject, scope (SUBJECT/MATERIAL), text, createdAt. Документи без scope читаються як SUBJECT для сумісності. Час публікації серверний. Назва дисципліни й заголовок матеріалу зберігаються на момент публікації. Матеріал підтверджує право викладача публікувати для дисципліни. При видаленні матеріалу оголошення залишається доступним автору й адміністратору для видалення. При зміні дисципліни матеріалу його попередні оголошення не переносяться автоматично: перевидайте їх з актуальною прив'язкою.

## Папки викладача

У профілі викладача вкладка «Мої публікації» групує власні матеріали за типом у розгортані папки: Лекції, Методички, Лабораторні, Практичні, Література, Відео/Аудіо, Інше. Папки показують кількість і підтримують порожній стан. Це представлення каталогу; шляхи файлів Storage не змінюються. Тип «Методички» додано до форми створення/редагування та фільтрів каталогу. Наявні матеріали залишають свій тип; щоб перенести стару методичку з «Література», змініть її тип через редагування в каталозі.

Firestore snapshot listener оновлює банери без перезапуску; підписка знімається при зміні дисципліни або виході з екрана. У разі втрати мережі можливі кешовані дані, публікація підтверджується після синхронізації. Правила забороняють студентам публікувати, викладачам — публікувати від чужого імені або видаляти чужі оголошення. Усі автентифіковані користувачі можуть читати оголошення.

Перед використанням опублікуйте правила з кореня проєкту:

```powershell
firebase deploy --only firestore:rules --project stefanykhub
```

Запити фільтрують за одним полем, сортування виконується в додатку; складені індекси не потрібні. Для дуже великих історій оголошень варто додати серверну пагінацію та архівацію.
