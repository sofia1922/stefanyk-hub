# Лабораторна робота 11 — готові матеріали

- `Лабораторна_11_Звіт.docx` — редагований Word-звіт; впишіть своє ім’я та групу.
- `Lab11_Report.pdf` — PDF для перегляду та друку (17 сторінок).
- `REPORT.html` — версія для браузера; відкривається разом із папкою evidence.
- `REPORT.md` — текстова версія.
- `evidence/lab11/` — 12 фінальних UI-скриншотів із суфіксом `_PASS`; `_FAIL` збережені з попереднього запуску для історії.
- `evidence/firestore-console.png` — справжній скриншот документа тимчасового студента у Firebase Emulator Suite. Акаунт після фіксації видалено.
- `evidence/unit-tests.png` — знімок HTML Test Execution Report з фактичним TAP-виводом.
- `results/` — оригінальні JUnit XML, TAP, JSON та текстові протоколи.

Підсумок основного набору: 12/12 функціональних сценаріїв (6 позитивних, 6 негативних), 5/5 Unit-тестів, 3/3 інтеграційних сценаріїв. Додатковий регресійний набір містить 53 + 31 перевірку.

Виявлено й виправлено оброблення системної кнопки «Назад» у панелі фільтрів. Окремо виправлено несумісність старої Espresso з API 37 та селектори нових UI-тестів. Початкові збої не приховано: їхні протоколи збережено.

## Код і повторний запуск

- UI: `app/src/androidTest/java/com/example/stefanykhub/Lab11FunctionalTest.kt`.
- Unit: `tools/demo/security/crypto.test.mjs`.
- Інтеграція: `tools/demo/lab11-integration.mjs`.
- Генератор звіту: `tools/demo/build-lab11-report.py` (залежність python-docx; для перевірки PDF використано PyMuPDF).

Для відтворення потрібні запущені емулятори Firebase, API та Android Emulator. Команди наведено наприкінці звіту. Запускайте UI-тести на тестовому емуляторі: Gradle connectedDebugAndroidTest встановлює та після завершення може видалити тестований застосунок і його локальні дані. Фінальну debug-збірку після тестування встановлено знову.

Для додаткового прямого скриншота Firestore тестовий студент тимчасово залишався через `LAB11_KEEP_EVIDENCE=1`; після отримання скриншота він видалений. Звичайний запуск інтеграційного скрипта очищає його автоматично.

Звіт перевіряє локальну debug-збірку. Експорт навчальних звітів з самого застосунку, хмарна доставка SMTP та Google OAuth у ці результати не включені.
