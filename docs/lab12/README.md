# Лабораторна робота №12

Composite для фільтрації каталогу та Facade для підготовки аналізу складності.

- `Лабораторна_12_Звіт.docx` — звіт для здачі.
- `REPORT.md`, `REPORT.html` — доступні для перегляду версії звіту.
- `diagrams/` — UML до й після змін у PNG та вихідні Mermaid-файли.
- `results/baseline/` — протоколи 24 початкових модульних тестів.
- `results/final/` — протоколи 42 фінальних модульних тестів.
- `results/summary.json` — команди, підсумки та відомості про зібраний APK.
- `results/*.before.txt` — початкові версії двох змінених екранів.

Гілка: `lab12-composite-facade`.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug --console=plain
python tools/demo/build-lab12-report.py
```

Для генерації звіту потрібні `python-docx` та `Pillow`. Скрипт читає збережені результати з цієї папки; новий запуск Gradle автоматично їх не замінює.

Нових тестів: 10 для Composite та 8 для Facade. Один із 10 тестів Composite порівнює нову фільтрацію зі старою на 2592 конфігураціях. Наявний `DifficultyFeedbackTest.kt` збережено без змін.

Debug APK зібрано. Запуск на Android та інструментальні UI-тести не виконано: під час перевірки не було підключеного пристрою або емулятора.

Для ручної перевірки після підключення пристрою:

1. Відкрити каталог студентом; перевірити пошук, кілька вибраних курсів, обране та скидання фільтрів.
2. Зняти всі курси або типи; перевірити відсутність результатів.
3. Відкрити каталог викладачем; перевірити відбір власних матеріалів.
4. Відкрити панель складності; перевірити списки «Усі», «Позитивні», «Увага», підсумкові картки та відкриття діалогу.
5. Змінити реакції іншим користувачем; перевірити оновлення аналітики без повторного входу.
